# Pandas Research

## 1. What is Pandas?

Pandas is an open-source Python library used to work with structured data. It provides tools to organise, analyse, filter, clean and manipulate data.

## 2. What problems does Pandas solve?

Pandas helps data professionals work with datasets by allowing them to:

- Handle missing values.
- Remove duplicate records.
- Filter and sort data.
- Combine datasets.
- Calculate statistics.
- Import and export files such as CSV and Excel.
- Prepare data for analysis and visualisation.

## 3. What is a Series?

A Series is a one-dimensional labelled data structure. It contains values and an associated index.

For example, a Series could store the ages of five customers.

## 4. What is a DataFrame?

A DataFrame is a two-dimensional table containing rows and columns. Each column can contain a different data type.

For example, a customer DataFrame might contain customer names, ages and countries.

## 5. Why might data professionals use Pandas?

Data professionals use Pandas because it makes working with structured data easier and more efficient. It helps them explore datasets, clean inaccurate or incomplete records, calculate statistics and prepare data for reports, charts and machine learning.

Pandas is often used alongside NumPy, Matplotlib and machine learning libraries.
